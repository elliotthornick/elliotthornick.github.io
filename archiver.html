JaeForge Archiver

Our own compression engine, in a box.

In Testing

Free · Windows & Mac

Most archivers wrap somebody else's algorithm. The JaeForge Archiver runs an engine designed and built here from first principles: instead of storing a file, it stores a prediction of the file plus the correction — and on source code, that idea beat the most widely used compressor in history.

The benchmark, stated plainly

  • 26.1% vs gzip's 27.0% — average compressed size across a 38-file source-code corpus, per-file mode, SHA-256-verified round trips
  • 22.9% vs 25.1% — in whole-codebase mode
  • Honest scope — the win is on source code; bzip2 still finishes ahead, and the Archiver says so

Features

  • Archive whole folders — one file out, manifest included, every extracted file verified against its hash
  • Store-if-smaller — files that don't compress are stored raw, never bloated
  • Free — no accounts, no subscriptions, no gates; good tools should travel
